# Intake and review workflow

1. Discover candidate.
2. Record candidate/source.
3. Find the primary or official source.
4. Verify identity and current availability.
5. Decide disposition:
   - accepted
   - needs_review
   - deferred
   - dead
   - duplicate
   - rejected
6. If accepted, create a Resource entry.
7. Assign `review_level`.
8. Add evidence.
9. Add lightweight assessment only when justified.
10. Link to a Gap only if the relationship is editorially meaningful.
11. Set `added_at` and `last_reviewed_at`.
12. Enrich later instead of blocking ingestion on exhaustive review.
